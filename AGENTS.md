# Feather DB — agent instructions

The authoritative guide lives in **[CLAUDE.md](CLAUDE.md)**. Read that.

This file exists because `AGENTS.md` is the convention several tools look for.
It is deliberately a pointer rather than a copy: it used to be a 605-line
duplicate of CLAUDE.md that had drifted to 99% identical and was stale at
v0.16.0 while the project shipped v0.20.0 — two authoritative documents that
disagree are worse than one, because nothing tells you which one is wrong.

Keep it this short. If something belongs in an agent's instructions, it belongs
in CLAUDE.md.
